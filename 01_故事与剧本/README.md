# 01_故事与剧本 目录指南（通用模板）

本目录由**【窗口① 剧本策划专员】**专属负责写入，其他窗口（分镜、资产、视频）**严格只读**，严禁擅改剧本原文与台词。

## 目录结构

- **`世界观与大纲/`**：
  - 存放新剧的世界观设定文档、核心人物小传与角色圣经、分集剧情大纲（Outline）与题材合规审查报告；
  - 格式推荐为 Markdown（`.md`）。
- **`scripts/`**：
  - 存放逐集剧本正文，标准命名为：`第01集_<标题>.md`、`第02集_<标题>.md` 等；
  - 剧本中需包含场次、环境、动作描述与人物台词；
  - 正面近景对白建议单句不超过 8–10 字，为下游视频模型对口型留足生理气口。
