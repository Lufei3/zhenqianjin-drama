# 样片、后期与交付文件

这里存放粗剪、试拍候选、相邻镜头样片和成片。单镜生成前处理所选镜头的完整预检，步骤见 [04 导演分镜与单镜试拍](../02_规范与工具/templates/04_导演级分镜_模板.md)。后期配音、接点与字幕按 [07 音画与后期模板](../02_规范与工具/templates/07_音画与后期_模板.md)执行。

| 建议路径 | 用途 |
| --- | --- |
| `out/EXX/pilot_rough_vNN.mp4` | 用占位静帧和临时干声检查表演、气口和切点。 |
| `out/EXX/SXX_vNN.mp4` | 单镜候选，保留前版和实际提交设置。 |
| `out/EXX/SXX_lipsync_vNN.mp4` | 单镜后期口型同步候选，登记使用的原片与干声。 |
| `out/EXX/pilot_vNN.mp4` | 相邻镜头合成样片，记录用了哪些候选和录次。 |
| `out/EXX/样片审片.md` | 用 [06 样片验收表](../02_规范与工具/templates/06_样片验收_模板.md)记录基线、问题时间码、返工和准入。 |
| `out/EXX/RUNLOG.md` | 保留每次尝试的实际任务号、入口参数、引用版本、唯一变量、结果和实扣。 |
| `out/EXX_vNN.mp4`、`out/EXX_vNN.srt` | 同一版成片与独立 SRT。 |

`EXX`、`SXX`、`vNN` 换成实际编号。干声、底声与拟音的源文件见 [声音目录](../audio/README.md)。

## 合成与放量

1. 从有声静帧粗剪开始，依次替换已通过初选的候选。先取 2–4 个相邻镜头或约 12–25 秒，保留前后剪辑上下文。对同批镜头核对所用声音、空间和颜色参考。
2. 连放前版与新样片，再对出现问题的位置逐帧检查。接点、口型与字幕对实际最终帧率复核。字幕在终版时间线上重新对齐，以独立 SRT 同版输出。
3. 未通过的镜头保留在返工清单中。只改一项因素后回到同一上下文比较。同一缺陷连续重试两次都未改善，或本轮预算用尽时，回到问题所在的上游环节。相邻镜头样片通过后分批推进，每批核对交界处的连续性。
