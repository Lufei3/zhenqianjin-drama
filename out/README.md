# 样片、视频与合成

`out/EXX/` 存一集的粗剪、试拍成片和验收记录。文件名可采用以下约定：

| 文件 | 用途 |
|---|---|
| `pilot_rough_v01.mp4` | 第一轮用占位静帧和计时试读粗剪，先核对镜头内容、停顿和切点。 |
| `S01_v01.mp4` | 单镜候选。每次重拍保留上一候选及其验收记录。 |
| `pilot_v01.mp4` | 将通过初选的相邻镜头剪成完整一场，带对应对白、声效和字幕预览。 |
| `样片审片.md` | 由 [样片验收模板](../02_规范与工具/templates/06_样片验收_模板.md) 填写，记录使用版次、过审状态及返工范围。 |
| `RUNLOG.md` | 逐次记录镜号、模型和参数、素材版本、变更变量、结果和实扣（如有）。 |

工作配音和后期音轨存 `audio/`，例如 `audio/E01_S01.wav`。需后期口型同步的镜头，先测配音 WAV 时长，再留好前后气口。正式提交生成前，用 `python 02_规范与工具/tools/audit_shots.py shots/E01_spec.json --shots S01 S02` 核对本轮镜头的挂载和音频，镜号按实际范围填写。

看样片时连着播放整场，核对动作和信息是否清楚、同一人物和空间能否认出、对白及口型是否协调、切点是否承接动作。失败时在验收记录写具体镜号和问题，每次比较明确一项改动。通过后按现有样片基线推进余下场次。整集交付可使用 `out/EXX.mp4` 与 `out/EXX.srt`。
