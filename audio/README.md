# 配音与声音文件

样片先用已确认台词的原音或临时读词给静帧计时，再按选定的节奏制作正式音轨。按 `audio/EXX_SXX.wav` 交接外配干声，文件名对应分镜镜号。临时文件可加 `_draft` 后缀，声音轨道之间统一采样率。

| 路线 | 开拍前的准备 | 合成时检查 |
| --- | --- | --- |
| `sfx_only` | 登记动作声和环境底噪 | 同场底噪接得上，点声落在动作接触点 |
| `native` | 按原台词试读，确认自然气口能落进可用时长 | 逐字听校，核对口型和切点 |
| `vo_lipsync` | 交可读取的 PCM WAV。视频长度至少为 WAV 实测时长加 0.5 秒 | 检查句首和句尾的嘴形，与反应镜切换时保持句子连贯 |

同场底噪和拟音分轨。对白剪定后按成片时间线出 SRT，台词与已确认文本逐字核对。
