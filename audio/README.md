# 配音与声音文件

先用已确认的对白录制临时读词，和静帧一起确定语速、停顿和剪辑接点。需要对口型时，先选定正式干声再定生成时长。可复制的录音、语音和对口型说明见 [07 音画与后期模板](../02_规范与工具/templates/07_音画与后期_模板.md)。

| 路线 | 音频交接 |
| --- | --- |
| `sfx_only` | `dialogue` 留空。登记同场环境底声和需要同步的动作声，初检模型输出是否有误生对白。 |
| `native` | 原句和标点在 `dialogue` 与视频正文保持一致。把已确认台词的试读版和可用时长登记在工作记录。生成结果逐字听校。 |
| `vo_lipsync` | `dialogue` 保留原句，`audio_file` 选干声 WAV。视频正文写闭口表演。生成 `dur` 至少为 WAV 实测时长加 0.5 秒。剪入时长应容纳实际台词，需要跨镜延音时记录两镜的音轨位置。 |

## 干声格式和录次

- 工作默认单声道、48 kHz、16 bit 或 24 bit 整数 PCM WAV。导出兼容 Python `wave` 的 PCM；遇到兼容问题换标准 16 bit 整数 PCM。保留完整字头、字尾和自然气口。混音、环境声及拟音和干声分轨。
- 音频可按 `audio/EXX_SXX_vo_vNN.wav` 保存，临时读词加 `_draft`，试录版按录次递增。旧镜头中已有的 `audio/EXX_SXX.wav` 仍可作为源路径。`audio_file` 始终填写选用版的真实路径。
- 每次记录台词输入版本、说话主体、声线、语气、录次、整文件长度和实际可听区间，供剪辑按帧率同步。工具预检检查 WAV 读取和实测时长，声音是否清晰、原句是否完整、口型和点声是否对应在成片中确认。
- 需要转换时保留原文件。下列命令的输入和输出替换为不同路径，再确认导出文件的声道、位深、采样率和播放结果。

```sh
ffmpeg -i '<源音频>' -ac 1 -ar 48000 -c:a pcm_s16le '<新版本.wav>'
```

对白剪定、音画合成后按成片时间线输出独立 SRT，将所用音轨和字幕版本登记到 [成片目录](../out/README.md)。
