# G2 视觉资产与首帧

用已经确认的分镜和有声静帧粗剪开工。资产人员先看这组镜头要让观众看到什么，再核对站位、视线、主光、服装和道具接点。按同场镜头以最少的参考锁住这些信息。

## 1. 从派单确定本轮输入

样片派单通常在 `shots/pilot/EXX_assets_todo.json`，整集派单与分镜 JSON 同目录。先按路径和镜号确认可复用的素材。同一路径只派一次，`usages` 记录各镜用途，`required_for_video` 为 `true` 表示本批有视频任务直接挂载这张图。某个文件也可同时用来制作首帧，例如制作首帧和 Mode B 时复用同一张人物图。和分镜人员核对参考路径及镜头目的。

| 顺序与任务 | 先用什么 | 何时补做 |
| --- | --- | --- |
| 人物外观 | 已确认的同状态图，或一张能辨识五官、发型和衣领的定妆照 | 需要全身表演、视角跨度大或服装结构难复现时补三视图；换装或造型变化从已选基础形象派生 |
| 场景空间 | 一张已选场景主图。多镜复用，`refs.scene_plate` 指向主图，观察角度记在 `camera_angle` | 固定物位置或反打光向仍对不上时，明确平面关系后补一个机位。已有匹配的等距柱状全景时可切出所需视角 |
| 道具和生物 | 主图里的普通物件随场景复用 | 近景需要辨认、接触动作依赖它，或跨镜必须保持外观时，补独立形体参考；道具记在 `refs.props` |
| 构图辅助 | 主图与镜头文字先固定几何关系 | 多人站位、遮挡、朝向仍摆不清时画一张灰度辅助图，记在 `refs.sketch` |
| 正式参考帧 | Mode A 制作一张与最终画幅和入点一致的首帧 | 已确认入口支持双帧、尾帧能明确运动终态时用 Mode A+，增加尾帧。Mode B 只挂分镜里实际需要的已选正式参考 |

模板包括[人物定妆](../02_规范与工具/templates/01_角色三视图_模板.md)、[场景主图](../02_规范与工具/templates/02_场景与720全景_模板.md)、[道具和生物](../02_规范与工具/templates/03_道具与猛兽_模板.md)、[灰度站位](../02_规范与工具/templates/05_彩色白模站位图_模板.md)与[首尾帧](../02_规范与工具/templates/03_首帧与线稿_模板.md)。先填设置和绑定，再复制该次要提交的正文。资产设定卡的「设定」部分记录参数，「默认」小节是直接可复制的生图提示词。

## 2. 按用途设画幅和生图入口

画幅在项目总控和分镜 JSON 中登记。定妆照可从 3:4 或最接近的肖像档起步，三视图用 16:9，场景主图常用 16:9 说明空间，独立小道具可用 1:1。画幅选到能保留关键信息即可。宽场景主图也可服务竖屏，把主体位置、留白和画内关系按 9:16 重新组成正式首帧。竖屏交付时首尾帧用 9:16，横屏交付时首尾帧用 16:9，新项目缺省 16:9。分辨率在生图入口和成片导出分别登记。

新做图可从 Seedream 5.5 开始。实际入口中确认模型名、画幅、像素档、参考数量和挂载方式。通用画布的「0 积分畅用」可用时按当时显示的条件使用。人物提示词首句用根目录 [README](../README.md) 的资产风格句。场景、道具和正式首尾帧用全片风格句；灰度辅助图用几何信息。让角色图管身份、场景图管空间和主光、道具图管形体、构图图管位置。需要选择参考时，一张图只为它最擅长回答的问题服务。

生成卡先走文字预检。下列命令从项目根目录运行。

```sh
python 02_规范与工具/tools/audit_cast.py 'cast/场景名.md'
```

将示例路径换成当前批次准备提交的卡，逐张检查已完成的角色、场景和道具卡。做全库盘点时可传入 `cast/`。样片首尾帧和灰度图通过人工并排检查。提示词词面正确以后再检查输入版本、参考绑定和模型参数。

## 3. 先查单张，再按剪辑顺序看

先在实际观看尺寸看人物和道具能否辨认，再并排看前镜切出、本镜首帧与下镜入点。核对光源、人物左右、视线、表情起点、手部位置、道具朝向及运动方向。A+ 的尾帧还要对上动作结束姿态、预定切出位置及下一镜入点。

| 看到的偏差 | 这轮先改 |
| --- | --- |
| 脸、发型或衣领变样 | 核对每个人的参考绑定和服装版本，再调整对应角色图 |
| 背景、固定物或光向变动 | 核对同场是否使用同一主图，必要时补一个已明确方位的机位 |
| 脸对得上，手或物件没有接住 | 修改首帧的初始接触点与道具比例，保留原有角色和场景参考 |
| 起止帧都能单看，连着看却跨轴或动作跳跃 | 调整起止构图或把动作分成便于衔接的部分 |
| 灰度参考影响材质或光影 | 先在预演里定好几何关系，再以正式参考图和文字重做首帧 |

每轮保留前一版候选和对应的输入。记清镜号、图像版本、观测到的问题与本轮一项改动，挑通过的一版进入下一工序。

## 4. 交接选中资产

`cast/` 根目录存验收角色、场景、道具及其设定卡，`cast/frames/` 存正式参考帧。随手画的站位图、白模和故事板归入 `cast/sketch/`、`cast/blocking/` 或 `cast/storyboard/`，供预演和图像合成。`cast/canon/` 记录跨集复用的稳定设定及漂移。保留需要复用的已选版与替代版路径。锁版范围按 `cast` 和 `frames` 分开，锁定选中的 PNG：

```sh
python 02_规范与工具/tools/asset_lock.py lock --scope cast --file 'cast/场景名.默认.png' --reason '场景参考通过'
python 02_规范与工具/tools/asset_lock.py lock --scope frames --file cast/frames/E01_S01_first.png --reason '首帧通过'
```

同一范围可重复传 `--file`。图像锁表分别在 `cast/LOCKED.json` 和 `cast/frames/LOCKED_FRAMES.json`。换版时先列出正在使用旧版的镜号。首尾帧、场景和道具可填已选新路径；角色用于首帧时按 `cast/<角色>.<状态>.png` 查找。并存的造型使用不同状态名，同一状态更新时先归档旧图，再存入选中版本并重锁。更新受影响的引用并重新派单。交视频前对同一批镜头跑完整审计。哈希核对路径对应的文件，画面能否交付以人工看片为准。完整命令见[制作规范](../02_规范与工具/PIPELINE_SPEC.md)。
