# AI 短剧工业化制作全流程标准与工程框架（对齐 `PIPELINE_SPEC` v4.0 核心基线）

> **框架定位**：专为 AI 短剧高品质、规模化、工业级生产设计的标准工程脚手架。  
> **核心基线**：对齐 `PIPELINE_SPEC v4.0`（首帧定锚 · 信号提纯 · 单源驱动 · 音画分轨）。  
> **适用场景**：适用于国漫 3D、真人写实、古风玄幻、现代都市等各类 AI 影视短剧项目。

---

## 1. 核心制片参数规范（制片总控卡模板）

在启动任何新剧集前，请在项目根目录总控配置中锁定以下参数，严禁下游擅自漂移：

- **画幅比例**：`16:9` 宽银幕电影画幅（支持适配 `9:16` 移动端竖屏）
- **目标分辨率**：资产设计展板 `2K / 4K`，720 全景图 `3840×1920` (2:1)，写实首帧 `2K`，最终成片 `1080p / 2K`
- **单集时长**：`90–120 秒`（约 15–22 个高张力分镜，对齐 Cadence Wave 呼吸波浪节拍）
- **默认生图模型**：`seedream_5.5`（用于通用画布资产主图、写实首尾帧 `FRM` 合成）
- **默认视频模型**：`Seedance 2.5`（通用画布 / 网页即粘即用版，提示词严格 ≤240 字）
- **核心视频生产制式**：
  - **Mode A（单写实首帧 I2V · 主力，占 65–75%）**：仅挂 1 张由 Seedream 5.5 在画布合成的高精写实首帧 `FRM`；
  - **Mode A+（首尾双写实帧 I2V · 运镜利器，占 15–20%）**：全景切出起止机位合成首尾 2 帧，锁定大摇移与环绕运镜；
  - **Mode B（多参考图 · 仅作补充，≤10%）**：仅挂 `@场景` + `@角色`，**严禁挂载任何白模或线稿**。

## 3. 视觉资产生产铁律（四大工业级标准）

1. **角色纯人物空手铁律**：
   - 基础卡（`## 默认`）必须且只能是 **16:9 标准三视图设计展板**（正面、90度侧面、背面体态对齐）；
   - **双手自然下垂完全空手**，严禁佩戴或手持武器、手杖、包袱等任何外挂道具；
   - 展板右侧附带独立高精面部特写/微表情特写；所有外挂道具、受刑战损、换装一律以派生变体卡产出。
2. **场景三级空间流转标准**：
   - `【场景主视图】` ➔ `【3D剖切微缩空间模型盒】` ➔ `【多机位四宫格电影分镜展板】`；
   - 四宫格展板双连线引用【主视图（锁定光影材质）+ 微缩模型盒（锁定3D空间坐标）】；
   - 四宫格全机位必须为 **1:1 真实建筑全尺寸沉浸式实景实拍**（具有完整屋顶天花板与地面），彻底排除玩具盒或剖切沙盘。
3. **微瑕疵道具资产标准**：
   - 居中孤立展板，中性深灰底色，微距物理磨损与材质真实质感。
4. **资产全量锁版管理**：
   - 验收后由 `asset_lock.py` 写入 `LOCKED.json` 固化 SHA-256，下游严禁擅改。

## 5. 核心工具与自动化门禁使用指南

本工程内置完整的全自动审计工具，在推进到下一流程前必须 100% 通过门禁校验：

```bash
# 1. 资产设定卡自动化红线审计（提交前必跑，杜绝违禁词、格式漂移与道具外挂）：
python 02_规范与工具/tools/audit_cast.py cast/

# 2. 导演分镜表自动化门禁审计（检查 Cadence 节拍、8 大补偿层、台词字数限制）：
python 02_规范与工具/tools/audit_shots.py shots/EXX.md --skip-lock

# 3. 资产下载与全量锁版（生成 LOCKED.json 防篡改）：
python 02_规范与工具/tools/asset_lock.py lock --scope all --reason "第一集资产全量验收锁版"

# 4. 场景四宫格展板无损切片（提取反打/俯视/左侧/右侧机位）：
python 02_规范与工具/tools/slice_grid.py --input cast/<场景>.多机位展板.png

# 5. 全流程门禁与健康度综合测试：
python 02_规范与工具/tools/test_gates.py
```

## 6. 即梦通用画布「0 积分批量生产」工作流

1. **缺口派单**：窗口③ 分镜拆解完成后输出 `shots/EXX_assets_todo.json`；
2. **免费建点**：CLI 工具批量在即梦画布创建好 typed 节点、填入提示词、建立连线拓扑（0 积分）；
3. **网页出图**：制片人在网页端勾选 **「0 积分畅用」** 免费队列批量运行生成；
4. **拉回锁版**：通过 CLI 批量拉回至 `cast/`，运行 `asset_lock.py` 计算哈希入库，下游安全开工。
