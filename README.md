# AI 短剧制作流程与总控

本仓库的制作规范管理制片参数、分镜交接、视觉参考、配音、视频生成和成片验收。剧本、人物设定、世界观和原台词属于原始资料，按已有版本只读使用。流程可从制作方提供的分镜或镜头清单直接开始。

## 制作总控

| 参数 | 常用起点与确认方式 |
| --- | --- |
| 投放平台与画幅 | 沿用项目已定的平台和画幅。新项目以 16:9 为起点，竖屏交付用 9:16 单独构图。把最终画幅写入分镜 JSON 的 `aspect_ratio` |
| 成片分辨率 | 1080p 为默认交付档，横屏 1920×1080，竖屏 1080×1920。生成档位和最终导出档位分别登记 |
| 单集时长 | 沿用项目已定时长。新项目可按 90–120 秒排产，录词和粗剪后确认实际时长 |
| 样片范围 | 选已确认的连续镜头，建议 2–4 镜、12–25 秒，从最容易造成返工的一项入手 |
| 视觉参考 | 沿用已批准的造型、场景和色调。把人物辨识点、服装状态、主光方向、构图和道具位置记录在资产卡 |
| 声音 | 沿用已选声线和原台词，干声、环境底噪和点声分轨。外配口型优先交可测时长的 PCM WAV，字幕以剪定时间线为准 |
| 默认工具 | 图片可用 Seedream 5.5，视频可用 Seedance 2.5。开拍前核实实际生成入口、模型、时长档位、参考图数量和价格 |
| 预算 | 分批登记预估和已用积分。提交范围以批准的批次为准 |

风格句可引用已有项目确认过的文字。若只有参考图，可归纳它的媒介、用光、色调和材质，作为制作参数登记；资产卡生成前填入对应风格句。画幅、声线或视觉方案换版时，记录生效范围和受影响的资产。

## 开工入口

1. 按[制作规范](02_规范与工具/PIPELINE_SPEC.md)确定本轮镜头和样片验收目标。
2. 参考[分镜 JSON 模板](02_规范与工具/templates/05_单源分镜JSON_模板.json)与[分镜填写指南](shots/README.md)，从现有分镜继续，或为样片建立新的分镜 JSON。
3. 用脚本派生总控表、复制用提示词和资产缺口表。按[职责分工](02_规范与工具/WORKSPACE_MAP.md)交接，按[样片验收表](02_规范与工具/templates/06_样片验收_模板.md)逐项看片。

现行入口以本页及中文[制作规范](02_规范与工具/PIPELINE_SPEC.md)为准。仓库中的旧版规范和批量生成脚本可作历史资料查阅。
