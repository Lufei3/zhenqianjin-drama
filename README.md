# AI 短剧制作流程与总控

从项目方已确认的镜头清单、素材与制作限制开工。把生成前最难修的问题尽早暴露：先用静帧和声音安排时间，验收角色、场景与首帧，再小批生成。看过相邻镜头剪在一起的样片后，才扩大制作范围。

| 工序 | 做完后手上有什么 |
| --- | --- |
| G0 制作开工 | 本轮镜号、来源版本、制作参数、预算与验收目标 |
| G1 有声预演 | 带临时声音的静帧粗剪、剪辑时长、镜头起止状态 |
| G2 视觉资产与首帧 | 已验收并锁定的定妆参考、场景、道具和拍摄参考帧 |
| G3 单镜试拍 | 可送剪的单镜候选、生成参数和具体问题记录 |
| G4 合成与放量 | 通过四项验收的带声样片、可复用的镜头与声音参数 |
| G5 交付与复盘 | 成片、独立字幕、版次清单和下一批可用的制作修正 |

[制作规范](02_规范与工具/PIPELINE_SPEC.md)规定每一步何时可以交下一环节。[全流程提示词手册](02_规范与工具/PROMPT_PLAYBOOK.md)提供可以复制的提示词与使用位置。

## 制作总控

已确认的项目参数优先。其余参数采用下表起点，并记在[制片总控模板](02_规范与工具/templates/00_制片总控_模板.md)的当批记录里。剧本、剧情、人物关系、世界观、原台词和原定镜头由项目方确认，制作记录引用版本，保持源文件只读。

| 参数 | 默认起点 | 开工时锁定 |
| --- | --- | --- |
| 画幅 | 16:9。定竖屏时采用 9:16 原生构图 | 目标平台、画幅、字幕安全区、关键动作所需的可见范围 |
| 生成与导出 | 图片可用 Seedream 5.5，视频可用 Seedance 2.5。分发母版默认 1080p | 实际入口支持的模型、分辨率、时长档、挂图方式，以及最终导出要求 |
| 帧率 | 若主素材原生为 24 fps 且平台允许，时间线用 24 fps。其他情况先按来源和目标平台确定 | 时间线帧率和转帧方案，最终核对口型、切点和字幕 |
| 片长 | 按已批准的交付时长。无要求时可按 90–120 秒估算整集工作量 | 分镜的生成时长和剪入正片的时长分别登记，按自然表演和剪点计时 |
| 样片 | 2–4 个相邻镜头、约 12–25 秒 | 一项最值得验证的制作风险、镜号、粗剪版次和可验收的现象 |
| 音频 | 48 kHz PCM WAV 干声，单个说话者用单声道。对白、环境和点声可单独调整 | 每镜声音路线、录音或声线版本、时间线及字幕轨 |
| 视觉 | 定妆参考负责辨认人物，场景底图负责空间与主光，首帧负责本镜构图和姿态 | 已确认的画面参考、服装和道具状态、主光方向，以及用于本镜的参考文件 |
| 预算 | 只按批准的镜头批次报价和提交 | 积分上限、已用量、批次和任务 ID。相同问题连续两轮没改善，回到对应环节排查 |

### 资产风格句

> `<<待填写项目已确认的资产风格句>>`

全片风格句用于场景、道具和首帧。资产风格句用于定妆参考。可用已认可的参考图归纳媒介、主光、色调和材质，再登记为风格句。开拍前把确认值填入此处。每次调整参数只记一处事实来源，记录生效范围和需重审的镜号。
