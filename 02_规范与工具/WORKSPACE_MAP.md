# AI 短剧项目工作区目录职责与多工种分工说明书（`WORKSPACE_MAP.md` · 对齐 `PIPELINE_SPEC` v4.0 重构版）

> **目的**：本项目采用**3 大核心角色分工制片模式**（编导台、资产与首帧工坊、视频与后期合成台），通过单源事实（SSOT）与自动化脚本彻底消灭跨窗口手工传表、漏改与覆盖冲突。

## 二、 3 大核心工种角色标准作业流（进场即用）

### 角色 ①：编剧与导演分镜台（单源驱动 · SSOT）
- **管辖目录**：`01_故事与剧本/`, `shots/`
- **启动必读**：`README.md`、`02_规范与工具/PIPELINE_SPEC.md`（§3 运镜三阶、§4 信号提纯、§5 气口公式）
- **核心标准作业**：
  1. 剧本定稿录入 `01_故事与剧本/scripts/第XX集_<标题>.md`；
  2. 按照 `02_规范与工具/templates/05_单源分镜JSON_模板.json` 编写单源事实清单 `shots/EXX_spec.json`（单镜 Prompt 控制在 120–200 字，硬上限 240 字；Mode A 占 65–75%，Mode A+ 占 15–20%）；
  3. 运行自动化派生脚本：
     ```bash
     python 02_规范与工具/tools/build_episode.py --ep EXX
     ```
     一键自动生成：
     - `shots/EXX_master.md`（人类可读 13 列总控表）；
     - `shots/EXX_prompts.md`（纯净代码块，即粘即用）；
     - `shots/EXX_assets_todo.json`（自动比对锁版库生成的纯增量缺口派单表）。
  4. 运行轻量语法门禁：
     ```bash
     python 02_规范与工具/tools/audit_shots.py shots/EXX_spec.json --pre
     ```
     通过后通知【角色② 资产工坊】接单。

---

### 角色 ②：资产与首帧工坊（0 积分通用画布 · 首帧定锚）
- **管辖目录**：`cast/`（含 `frames/`, `sketch/`, `canon/`）
- **启动必读**：`shots/EXX_assets_todo.json`、`02_规范与工具/templates/01~03_*.md`
- **核心标准作业（0 积分省钱闭环）**：
  1. 读取缺口派单表 `shots/EXX_assets_todo.json`；
  2. 调用 CLI 批量在通用画布创建图片节点（不加 `--run`，0 积分）：
     - 角色纯空手基础三视图（`CHR-*-TURN`）：严守双手自然下垂无外挂道具铁律；
     - 场景主图与 720° 全景：用 `pano_to_grid.py` 2 秒投影生成纯净无字四机位与四宫格展板；
     - **写实首尾帧 `FRM` 合成**：在 0 积分画布挂载场景切片与角色三视图（构图极复杂时可挂 `cast/sketch/` 黑白线稿），用 Seedream 5.5 合成 100% 写实首尾帧，**彻底根除白模污染**；
  3. 用户在通用画布网页勾选「0积分畅用」一键生成并挑图；
  4. CLI 批量下载回本地对应目录，执行自动化门禁与全量 SHA-256 锁版：
     ```bash
     python 02_规范与工具/tools/audit_cast.py cast/
     python 02_规范与工具/tools/asset_lock.py lock --scope all --reason "锁定第XX集增量资产与写实首尾帧"
     python 02_规范与工具/tools/audit_shots.py shots/EXX_spec.json
     ```
     全绿放行后通知【角色③ 视效台】开拍。

---

### 角色 ③：视频与后期合成台（音频先行 · 受控视频 · 成片合成）
- **管辖目录**：`out/`, `audio/`（抽末帧回 `cast/frames/`）
- **启动必读**：`02_规范与工具/PIPELINE_SPEC.md`（§5 音画分轨、§8 门禁、§9 试拍卡点）、`shots/EXX_prompts.md`
- **核心标准作业**：
  1. **音频先行（Audio-First）**：对 `audio_mode == "vo_lipsync"` 镜头，先在 `audio/` 生成配音 WAV 确认实测时长，确保视频时长覆盖气口；
  2. **2 镜试拍卡点（Pilot Gate）**：放量出片前必先试拍 2 镜（1 镜写实首帧对白 + 1 镜首尾双帧/高速爆发），8 项指标全通方可放行；
  3. **放量生成与接力锁版**：
     - 在通用画布 / Seedance 2.5 节点粘贴提示词出片（单镜硬预算 ≤ 3 次尝试，每次仅改 1 变量，单集 80% 预算熔断）；
     - 连续动作镜头用 `extract_last_frame.py` 无损抽末帧入 `cast/frames/` 并锁入 `LOCKED_FRAMES.json`；
     - 所有提交结果与尝试记录只追加录入 `out/EXX/RUNLOG.md`；
  4. **成片合成**：执行口型对齐，`jimeng-novel compose` 或 FFmpeg 拼接视频与音轨，外挂 `EXX.srt` 字幕。

## 三、 多角色开场“一句话认领指令”

新开对话窗口时，直接将对应的一句话发给它即可就绪：

- **开【编导台】**：`你是本项目的【角色① 编剧与导演分镜台】，请按 02_规范与工具/WORKSPACE_MAP.md 认领 01_故事与剧本/ 与 shots/ 目录职责。维护单源清单 shots/EXX_spec.json（Prompt 严格 ≤240 字，Mode A 占 70%），运行 build_episode.py 派生总控表与派单表。`
- **开【资产工坊】**：`你是本项目的【角色② 资产与首帧工坊】，请按 02_规范与工具/WORKSPACE_MAP.md 认领 cast/ 目录职责。读取 shots/EXX_assets_todo.json，在通用画布通过 0 积分畅用按单生成纯空手三视图、720全景切片与写实首尾帧 FRM，严禁白模喂视频，验收后跑 asset_lock.py 锁版。`
- **开【视效台】**：`你是本项目的【角色③ 视频与后期合成台】，请按 02_规范与工具/WORKSPACE_MAP.md 认领 out/ 与 audio/ 目录职责。执行音频先行与 2 镜试拍卡点，受控出片并完成口型合成。`

## 四、 跨角色防踩踏 3 条铁律

1. **同一时间同一目录只允许一个角色写入**。
2. **单源派生不可逆**：严禁手工编辑 `shots/` 下的 `.md` 派生文件，一切分镜改动必须改 `EXX_spec.json` 并重新派生。
3. **未锁版不开拍，白模线稿不喂视频**：视频模型仅接受写实首尾帧（Mode A/A+）或极简纯正脸参考（Mode B），严禁任何中间过程草图流入视频生成端。
