# 制作分工与目录

制作顺序以 [制作流程](PIPELINE_SPEC.md) 为准，具体画幅、风格和交付目标见 [项目总控](../README.md)。分镜、资产、后期是三项职责，同一个人可以承担多项。每份源文件由负责该项职责的人合并修改，避免同时覆盖。

| 职责 | 写入位置 | 每次交付 |
|---|---|---|
| 分镜 | `shots/` | 登记已确认的镜头目标、时长、分镜 JSON 和切点。运行工具派生分镜表、提示词和素材缺口。 |
| 资产 | `cast/` | 按样片清单交付角色、场景和参考帧，记录定妆、场景方向与状态。人工挑选通过的版本再锁版。 |
| 视频与后期 | `audio/`、`out/` | 试读或临时配音、静帧粗剪、试拍记录、带声音的样片与验收记录。需要复用某段尾帧时，交给资产确认后再入 `cast/frames/`。 |
| 制作维护 | `README.md`、`02_规范与工具/`、项目技能 | 保持入口、模板和工具一致。平台参数以当前使用的模型和入口为准。 |

## 按一场完整的戏交接

1. 分镜负责人从已确认的镜头里选能代表常见制作难点的一组。用 2–4 个连续镜头、12–25 秒检验，要交代时长、主要动作和镜头接点。用当前集的分镜 JSON 登记计划，`E01` 为示例。
2. 后期读出或录下台词，用占位静帧把每镜时长、视线方向、动作接点和声音粗剪出来。分镜负责人看带声音的粗剪，同步修正分镜 JSON。需口型同步的镜头在送生成前按配音 WAV 的时长留出余量。
3. 分镜负责人按[制作规范](PIPELINE_SPEC.md#2-从-json-派单并锁定样片使用的图)用 `--shots` 选定本轮镜头，运行分镜预检和派生，把 `shots/pilot/EXX_assets_todo.json` 交给资产。资产先做这一场需要的参考图和首帧，已有合格的场景图可用 `refs.scene_plate` 复用。默认用 Mode A，明确需要并验证平台支持后再选 A+ 或 B。
4. 资产按文件锁定通过的图。正式试拍前，后期对同一份 JSON 的同一批镜号跑不带 `--pre` 的审计，并核对模型能力、素材挂载和时长。实际生成按对应入口的报价与提交规则执行。
5. 后期把样片剪回完整一场，带台词、声效和字幕一起看片。在 `out/E01/` 存粗剪和验收记录，记录未过项目对应的镜号及原因。样片通过后，分镜负责人按场派发剩余镜头及增量素材需求。

派生文件的修改由分镜负责人回写源 JSON。每轮返工先定位问题来源：动作和接点回到分镜，外观和空间回到场景参考或首帧，表演或口型问题按生成或后期环节处理。已验收素材要换版时，保留旧版本并检查引用它的镜头。
