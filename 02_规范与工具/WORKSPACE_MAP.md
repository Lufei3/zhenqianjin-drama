# 制作分工与交接

[制作规范](PIPELINE_SPEC.md)管理各阶段的进入和通过条件，[项目总控](../README.md)记录制作参数，[提示词手册](PROMPT_PLAYBOOK.md)索引模板。个人项目可一人负责多项，按阶段留下可接续的记录。

| 职责 | 写入位置 | 移交内容 |
| --- | --- | --- |
| 制片与制作维护 | `README.md`、`02_规范与工具/`、项目技能、当批制作记录 | 输入版本、规格、报价与批准范围、验收结论和后续执行规则 |
| 分镜 | `shots/` | 镜号、场次、时长、提示词、引用与接点。维护单集 `EXX_spec.json`，从它派生给资产和后期的文件 |
| 视觉资产 | `cast/` | 选中的人物、场景、道具与参考帧。记录批次、锁表和受影响镜号 |
| 视频生成 | `out/EXX/` | 单镜候选和已选版、所用参数、任务 ID、实际费用与可用剪辑区间 |
| 声音与剪辑 | `audio/`、`out/` | 干声、粗剪、声效轨、带声样片、字幕和母版。用时间线记录版本 |
| 审片 | `out/EXX/` | 通过或返工、受影响镜号和时间码、返工负责人及复查结果 |

剧情、人物、世界观与原台词归输入资料保管。制作方引用版本和场次，把技术变更写进分镜、派单、粗剪或审片记录。

## 交接表

| 阶段 | 谁交给谁 | 接收时核对 |
| --- | --- | --- |
| G0 制作开工 | 制片 → 分镜、后期 | 输入版本、画幅/时长/声画要求、目标镜号、要验证的问题 |
| G1 有声预演 | 分镜和剪辑 → 视觉资产 | 粗剪版、对白实测、入点和出点、场景和视线、样片所需素材 |
| G2 视觉资产与首帧 | 视觉资产 → 视频生成 | 图片版次、每镜挂载角色、场景或帧、角色和方位连续性、锁表及已知限制 |
| G3 单镜试拍 | 视频生成 → 声音与剪辑 | 审计结果、候选文件、入出点时间码、声音模式、失败项和接力依赖 |
| G4 合成与放量 | 剪辑和审片 → 制片与各制作岗位 | 样片版本、逐项验收、可复用的参数与素材、下批镜号和费用范围 |
| G5 交付与复盘 | 后期和制片 → 交付方及后续制作 | 导出清单、实际规格、复盘问题及已验证的防返工做法 |

## 版本与修改

- 分镜修改先改 `shots/EXX_spec.json`，用同一镜号重新派生。按镜号生成的交接文件在 `shots/pilot/`，要保留的批次存快照。完整分镜与已通过的镜头版本继续保留。
- 视觉资产候选、锁定版本和表演候选独立编号。替换参考图前核对受影响镜号，按 [制作规范 G2](PIPELINE_SPEC.md#g2-视觉资产与首帧)验收并锁定选中的图。
- 后期记录视频文件、WAV、剪辑时间线和字幕的配套版本。需要接力尾帧，由视频生成提供实际时间码和片段版本，资产验收后锁在 `cast/frames/`。
- 续做时查最新验收和试拍记录。负责人按镜号与时间码收口问题，同一变更涉及多项交付时由制片确定受影响范围与重新通过的阶段。
