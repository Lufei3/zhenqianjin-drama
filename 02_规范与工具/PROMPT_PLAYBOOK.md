# 从开工到交付的提示词手册

先确定提示词的收件人。给制作助手的指令用于核对、排片、审片。给图像或视频模型的提示词只描述该次要生成的画面、动作或声音，画幅、档位、挂载、版本和费用另填在工具参数或批次卡。复制模板后替换所有 `<<占位>>`，只填写已确认的项目资料。

| 工序 | 提示词入口 | 输出 |
| --- | --- | --- |
| G0 制作开工 | [参数核对](#g0-参数核对) | 批次卡和待核实项 |
| G1 有声预演 | [分镜与时长安排](#g1-分镜与时长安排)、[有声预演表](templates/00_有声预演_模板.md) | 镜头时间表和预演检查记录 |
| G2 视觉资产与首帧 | [角色](templates/01_角色三视图_模板.md)、[场景](templates/02_场景与720全景_模板.md)、[道具](templates/03_道具与猛兽_模板.md)、[首帧](templates/03_首帧与线稿_模板.md)、[可选站位图](templates/05_彩色白模站位图_模板.md) | 资产卡、可复用参考、实际拍摄用帧 |
| G3 单镜试拍 | [视频模式与声音路线](templates/04_导演级分镜_模板.md)、[单镜候选评估](#g3-单镜候选评估) | 能剪入样片的候选和当前失败原因 |
| G4 合成与放量 | [音画操作和剪辑提示词](templates/07_音画与后期_模板.md)、[样片验收表](templates/06_样片验收_模板.md) | 带声粗剪、通过结果和可复用参数 |
| G5 交付与复盘 | [交付核对](#g5-交付核对)、[交付复盘模板](templates/08_交付复盘_模板.md) | 可交付文件清单和确认过的改进 |

## G0 参数核对

复制给负责制片检查的助手。

```text
根据下列已确认输入填写本批制片总控。
输入：<<分镜版本、允许使用的素材、交付平台与已有制作限制>>
制作工具：<<实际入口及模型能力>>
本轮范围：<<相邻镜号、预计成本上限、需要验证的风险>>
输出一张表：已确认值、依据、待核实值、会影响的镜号、下一位负责人。
分别核对生成和导出的画幅、分辨率、帧率、声音路线与素材版本。
把样片验收目标写成可以实际观察的行为或接点。信息缺失时写“待确认”。
照录原定台词和镜头限制，引用源版本。
```

## G1 分镜与时长安排

复制给分镜或剪辑助手。先排时间，再准备正式参考图。

```text
用已确认的镜头清单和临时音轨规划一段连续样片。
输入：<<镜号、批准的表演动作和对白、素材版本、目标画幅、可用生成时长档>>
实测：<<每条试读的起止、动作落点、必须保留的停顿>>
按源镜号顺序输出：本镜要看见或听见什么、入点状态、出点状态、画面左右与视线、声音路线、预计生成时长、预计剪入时长、后镜接点。
先给自然气口和动作完成留出时间。句子或动作装不下时，列出需要重排的切点及影响，保持已批准的对白和故事内容原样。
最后列出最少需要的已选参考和本次粗剪要验证的两处接点。
```

表里只写实际测得或明确标为预计的值。剪入时长是时间线上要用的部分。生成时长是模型实际接收的档位，可以留出切头切尾余量。

## G3 单镜候选评估

复制给看片助手。把要比较的实际预览、同一份镜头要求和已批准的参考一并提供。

```text
按同一入点、动作终点和声音要求比较这些候选。
输入：<<镜号、制作目标、参考版本、参数、候选文件、上一轮的问题与时间码>>
分别看首段、动作最明显处和尾段，再按正常速度看一次。
输出：候选号、可观察的符合项、失败时间码、影响剪辑的原因、是否可剪。
保留成功项，推荐下一轮只改一个变量，写明预期能改善的现象。
缺失画面或音频时标记待验。不要根据提示词推断成片已经实现的效果。
```

首帧已经偏、回 G2；首帧对而动作失败、先缩小该镜的运动指令；时间或口型不够、回 G1 检查实测声音和镜头入点；镜头各自可用却接不上、先在 G4 调整剪点和音响桥。

## G5 交付核对

复制给交付或审片助手。可只给输出清单做文件核对，声音和画面验收需要对应媒体。

```text
核对最终导出和已批准的样片基线。
输入：<<时间线版次、成片、SRT、交付规格、已确认镜头清单和验收记录>>
依次记录：文件是否齐全、时长和导出参数、对白与字幕是否一致、已知画面或声音问题有无复发。
对可见的问题给真实时间码、涉及镜号、应回到的制作环节和建议复核对象。
标明只查过文件规格的项目，以及因缺少证据而待验的项目。
交付清单附文件路径与版次。复盘只提有现有观察支持的制作改动。
```
