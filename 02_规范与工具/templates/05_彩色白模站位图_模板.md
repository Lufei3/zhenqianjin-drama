# 灰度站位参考

当单张场景参考和文字仍无法说明多人相对位置、遮挡、运动方向或剪辑轴线时，用站位图统一空间关系。先手画或用简单几何搭图。只在需要把这张图给生图入口时，用下面的正文生成或重绘。站位图的职责是提供位置、比例和遮挡，正式风格交给最终参考帧。

| 项目 | 填写 |
| --- | --- |
| 影响的镜号与视点 | <<镜号、观察位置与高度>> |
| 固定参照 | <<场内两个能辨别方向的固定物>> |
| 人物位置与体态 | <<画内左右、前后、相对高度、起始朝向>> |
| 动作及接触 | <<人物与关键实物的起始接触点、运动方向、结束位置>> |
| 视线与切点 | <<指向的位置、可能遮挡谁、下一镜从哪里接>> |

**手绘或几何预演**：先在俯视平面画出固定参照、人物轴线及前后镜视点。再从本镜实际视点导出一张轮廓图以供构图。画幅同正式首帧，灰阶分出前后层次即可。

**生图正文**：用入口支持的画幅与参考方式。只输入已有构图信息。

```text
<<画幅>>灰度构图草图，<<景别和观察位置>>。两个固定参照分别位于画面<<位置>>和<<位置>>。用简洁的等比例轮廓画出<<人物与位置>>，他们面向<<方向>>。<<关键物>>位于<<位置>>，<<需要的遮挡和手部接触>>清楚。纯净浅灰背景，黑灰构造线与平涂灰块。
```

**选图检查**：对照镜头清单检查左右、比例和视线；超出机位一侧的物体以遮挡关系表现。若写进分镜 `refs.sketch`，保存为 `cast/sketch/<<集号>>_<<镜号>>_sketch.png` 或沿用 `cast/blocking/` 的已有路径。先把它用在静帧预演或图像合成，再用正式首帧作为视频参考。
