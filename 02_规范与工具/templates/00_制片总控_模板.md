# G0 制片总控与批次卡

基础参数由根目录 `README.md` 定义。本卡记录本次实际选择和变化。只登记已获准用于生产的材料。

| 项 | 应填写的内容 |
| --- | --- |
| 批次、负责人、版本 | 批次号、集号、镜号、分镜版本、决定日期 |
| 已确认输入 | 文件或资产版本、用途、镜头边界和声线版本 |
| 本轮要验的风险 | 一个现场可辨的现象，例如切换角度后位置是否一致 |
| 画面交付 | 平台、画幅、导出分辨率、时间线帧率和字幕安全区 |
| 声音交付 | 干声格式、采样率、跟录或后期路线、独立字幕要求 |
| 生成入口 | 图片模型、视频模型、每种模式支持的挂载数、时长档、可用分辨率 |
| 参考版本 | 画风或锁定参考、角色外观、场景主图、声音素材版本 |
| 样片范围 | 2–4 个连续镜头起步，预计剪辑时长及对应的验收人 |
| 成本 | 本轮估价、已批准上限、耗用记录、下一批的提交条件 |

## 找不到的两类信息

- 可继续准备的项目。已有镜号、时间安排或素材时，完成静帧预演和派单草稿。
- 会影响本批成片的项目。在上表写明缺的值、影响的镜号和谁来确认，确认后再组装该批任务。
