# G5 交付与复盘

| 项 | 填写内容 |
| --- | --- |
| 交付范围 | 集号、批次、时间线版次与批准的镜头 |
| 视频 | 成片路径、画幅、分辨率、帧率、时长、导出规格 |
| 字幕 | SRT 路径、版本、编码，与成片同一时间线 |
| 可追溯来源 | 分镜 JSON 版本、素材锁表、样片审片表、生成日志、声音版本 |
| 验收 | 可以交付、返工或待验。登记验收人及最终播放设备 |

| 检查 | 通过条件 | 结果与时间码 |
| --- | --- | --- |
| 出口规格 | 实际成片参数符合已确认的投放要求 | 待验 |
| 版本一致 | 采用已选镜头、指定声轨和最终版字幕，文件命名与清单一致 | 待验 |
| 画面和剪点 | 按最终速度看首尾及问题镜，切换稳定，动作完整 | 待验 |
| 听感与字幕 | 整集听一次，检查切点、音量、对白、口型及字幕进出 | 待验 |

| 问题与观察依据 | 应回到哪一步 | 修改什么参数或操作 | 涉及的后续镜号 |
| --- | --- | --- | --- |
| 待填 | 待填 | 待填 | 待填 |

将可复用的修正写回制作总控、当前参考或分镜中的对应位置，再从受影响的环节复核。记录生成耗用时以实际任务记录为准。
