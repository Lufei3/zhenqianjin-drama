# 0 积分写实首尾帧合成与无色线稿参考模板（`FRM-E<<集>>-S<<镜>>`）

> **【使用说明】**：本模板用于在即梦通用画布（0 积分畅用）中，利用 **Seedream 5.5** 将场景切片、纯空手角色卡（以及可选的无色线稿构图参考）合成为一张 **100% 写实电影画质首尾帧**。
> 视频模型 Seedance 2.5 阶段仅喂该写实首帧（Mode A），从而**彻底消灭白模染色与塑料假人感**！

---

## 挂载参考（通用画布 · 0 积分畅用节点）
- **必挂场景**：`@场景` = `cast/<<场景名>>.机位_<<角度>>.png`
- **必挂角色**：`@角色A` = `cast/<<角色A>>.默认.png`（如有双人同框，按需加挂 `@角色B`）
- **选挂构图（仅极端复杂站位使用）**：`@草图` = `cast/sketch/E<<集>>_S<<镜>>_sketch.png`
  - *注意：草图必须为纯白底黑线极简构图线稿/火柴人，零色彩、零塑料高光，仅用于辅助生图，严禁流入视频模型！*

---

## 0 积分生图执行提示词（合成写实首帧）

```text
写实高精度国漫3D CG电影画面截图，16:9宽银幕，浅景深电影光影。完全采用{{场景}}的空间结构、材质细节与冷暖布光；将{{角色A}}（<<服装关键材质锚点，如：亮橙色冲锋衣真实布料折痕>>）置于<<画面左侧中景>>，<<精确起始姿态与手部接触实物，如：双手撑在旧木桌沿微前倾>>，视线紧盯<<具体实物锚点>>；将{{角色B}}置于<<画面右侧近景过肩背影>>，<<起始姿态>>。<<若挂载了草图则加一句：严格遵循{{草图}}的画面构图、透视比例与人物站位关系。>>空气中悬浮微尘，窗外暴雨斜落，人物皮肤毛孔与衣料折痕自然真实，无任何文字、字幕、标签与水印。
```

## 落盘与锁版
- 保存路径：
  - 首帧：`cast/frames/E<<集>>_S<<镜>>_first.png`
  - 尾帧（若为 Mode A+）：`cast/frames/E<<集>>_S<<镜>>_last.png`
- 锁版命令：
  ```bash
  python 02_规范与工具/tools/asset_lock.py lock --scope frames --reason "锁定第XX集写实首尾帧"
  ```
