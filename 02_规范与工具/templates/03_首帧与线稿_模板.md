# <<集号与镜号>>参考帧

参考帧负责锁定当前镜头的构图、人物位置和姿态。先根据有声静帧粗剪核对入点与出点，再完成画面。将参数、参考绑定和生图正文分开记录。

| 参数 | 填写 |
| --- | --- |
| 模式 | Mode A 用一张首帧。Mode A+ 可用首帧和尾帧说明构图或动作终态，先确认生成入口支持两张帧图 |
| 画幅和像素 | 与分镜 JSON 的 `aspect_ratio` 一致。竖屏按 9:16 重新排主体和留字幕的空间，横屏用 16:9。用入口可用、细节足够的档位 |
| 出图入口 | 图片可从 Seedream 5.5 起步，记录实际模型、参考图顺序、生成参数及版本。变更其中一项时保留上一版对照 |
| 保存路径 | 首帧沿用 `refs.first_frame`，尾帧沿用 `refs.last_frame`。格式为 PNG |

## 参考挂载

| 参考 | 负责什么 |
| --- | --- |
| 当前场景主图 | 根据 `refs.scene_plate` 对齐固定物、空间关系和主光方向 |
| 出镜角色 | 使用所需服装和造型的已选图。每张参考明示它负责的人物 |
| 手部或道具 | 关键位置、朝向或比例单靠前两项不清楚时，挂该物件的选定图 |
| 前镜选中切出画面 | 只有同一动作或姿态需要接续时使用。以实际剪点画面为准 |
| 灰度站位图 | 当同场布局、遮挡或轴线仍有歧义时，加给生图工具说明几何关系 |

引用只在入口支持的方式下绑定。按图的任务选择最少需要的参考。如果入口限制数量，优先保留最难由文字复现的信息。一张首帧只登记它真正使用的参考。

## 首帧正文

```text
<<逐字填入 README.md 的全片风格句>>
<<画幅与景别>>。从<<可辨认的观察位置>>看向<<空间参照物>>。<<出镜人物>>在画面<<左右及前后位置>>，身体朝<<方向>>，视线落在<<具体对象或位置>>。动作开始前，<<肩、手或身体重心的姿态>>，<<关键物的方向和接触位置>>。光从<<来向>>照到<<部位>>。
```

## 尾帧正文（Mode A+）

将已选首帧和相同的角色、空间参考作为身份与环境依据。对比起止两帧的实际运动范围和生成时长。

```text
<<逐字填入 README.md 的全片风格句>>
沿用首帧的人物、服装、场景材质和主光方向。动作结束时，从<<结束观察位置>>看向<<参照物>>。<<人物>>停在画面<<位置>>，视线落到<<实物或位置>>，<<肢体或道具的最终状态>>。<<需要接到下一镜的构图关系>>。
```

## 选图与交接

- 把前镜切出、本镜首帧和后镜入点按时间线并排看。核对脸、服装、景别、轴线、视线、手部、道具状态和光向。两帧路线不能同时说清楚时，回头简化运动或拆镜。
- 直到角色、服装和固定背景都可辨，再比较需要调整的位置。每次保存一版并记录一项变化。
- 选中的帧按镜号保存。例如 `cast/frames/E01_S01_first.png` 或 `cast/frames/E01_S01_last.png`。只锁已检查的帧，锁好后复查分镜和派单。
