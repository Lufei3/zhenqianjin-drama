# 导演分镜编写指南

从 [05 分镜 JSON 模板](05_单源分镜JSON_模板.json) 复制到 `shots/EXX_spec.json`。模板里的空场镜仅演示字段。写分镜时换成已确认的镜头安排。

| 项目 | 填写方法 |
| --- | --- |
| `aspect_ratio`、`dur` | 画幅来自项目总控。时长从读词、表演和动作接点反推，再按实际生成档位调整 |
| `shot_goal`、`handoff_note` | 一镜的制作或表演目标，下一镜从哪个物理状态接 |
| `camera_angle`、`first_frame_note` | 视点、画内的人和物、人物与窗光方向、入点的姿态和视线 |
| `characters` | 角色名、造型状态和在场码。只见手部也属于 `on_screen` |
| `refs` | `first_frame` 为模式 A 首帧，A+ 增加 `last_frame`。B 独用 `mode_b_refs`，声明正文别名。复用场景底图用 `scene_plate`，道具路径放 `props` |
| `audio_mode`、`dialogue` | `sfx_only` 无台词。 `native` 在正文带台词。 `vo_lipsync` 把台词留在 `dialogue`，填写 `audio_file`，正文只写闭口表演 |
| `video_prompt` | 视点、一个主要动作、终态和必要的动作声。用画内实物或真实站位说明视线。结尾写「无字幕」，净字数最多 240 |

用 `build_episode.py` 派生提示词集，复制生成文件里的代码块作为实际视频提示词。资产工序看总控表中的首帧要求与生成的资产派单。剪辑交接使用入点和出点，回头修正内容时改 JSON 再重新派生。
