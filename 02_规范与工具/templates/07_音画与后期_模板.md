# G4 音画合成与放量

开拍前按此页准备临时读词与正式干声。单镜初选后从有声静帧粗剪换入已选候选。初轮取有因果或动作承接的 2–4 个相邻镜头，12–25 秒是便于比较的起点。保留前后的入点和出点，按剪定节奏连着看。

## 1. 计时与准备音频

| 路线 | 先准备什么 | 验收什么 |
| --- | --- | --- |
| `sfx_only` | 取得同场可循环的底声。列出必须和动作对齐的点声。 | 听不到模型误生对白或突兀的静音，接触声贴在动作上。 |
| `native` | 逐句试读已确认的原文，标记自然停顿和可用时长，再按视频入口的档位选生成时长。 | 按来源逐字听校，包括漏字、被截的尾字和说话人。检查嘴形、动作和反应顺序。 |
| `vo_lipsync` | 先选已确认的声线和干声版本。优先用单声道、48 kHz、16 bit 或 24 bit 整数 PCM 的 WAV。保留自然起落和换气。生成时长 `dur` 至少为所用 WAV 实测长度加 0.5 秒，按素材分配前后气口。 | 对可见口型做一次后期同步，标记首音、明显闭唇或爆破音与末音。剪入时长 `cut_duration` 需容纳所用台词；计划跨镜延音时，在衔接记录中明确两侧的声音进出。口型无法稳定时选听者、手部或已有遮挡镜头承接原音。 |

`audio_file` 填选定的干声版本。PCM 必须能被仓库的 Python `wave` 读取。纯 PCM 16 bit 是兼容起点。带头尾静音的 WAV 按整文件实测，另记可听对白时间段和实际剪入位置。采样率、位深和单声道在导出或导入时核对。自动检查能验证 WAV 可读和预留时长，同步与可懂度在剪辑时间线上判断。

### 录音或语音生成指令

声音入口支持独立风格说明时，只把第一块用作说明，把第二块用作实际朗读文字。用于只接收朗读文字的入口时只填第二块。所有需要送出的内容限于已确认的文字或音频输入。

```text
沿用确认的<<声线或声线参数>>。以<<可表演的语气>>读一遍，语速<<正常或指定的读法>>，在<<原句对应的停顿点>>自然换气，句尾完整落下。只交该说话人的干声，保持音量稳定。
```

```text
<<已确认的原台词，逐字逐标点>>
```

有必要时另录一版节奏略有差异的干声。文件以录次编号，保留原版，实际试读和同步后再选。音色、语气或时长异常优先更换同一输入的一次录次。已锁原句需要保留时，留足时间或用后期声画方案。

### 对口型与声效指令

只有入口有相应功能时才提交下列说明和对应文件。后期口型入口须支持所选画面和已确认音频的组合。没有说明栏时使用功能参数并用同样的标准审片。

```text
把<<所选干声>>的说话动作同步给画面中的<<可明确定位的主体>>。从<<首音对应位置>>到<<尾音对应位置>>处理可见口型。保持原片的构图、机位、身份、光线及其它表演。
```

```text
只生成<<声源>>在<<空间或距离>>产生的<<单次接触声或稳定持续底声>>。<<音量与衰减>>，留可剪的头尾。无对白。
```

## 2. 剪辑、混音和匹配

1. 在确定的交付画幅和帧率下建主时间线。先放已选对白或临时读词、标出台词和主要动作的位置，再放选中的视频段。记录每镜使用的源文件版次、源片入出点和成片入出点。现有开头或结尾含生成缓冲时按实际画面裁掉。
2. 左右位置、视线、手持物和光向按前后镜逐项比对。亮度、色温和对比轻微差异可按已验收的主参考做统一匹配；角色、物件或空间发生明显变化时，把对应镜头转回素材或生成工序。
3. 对白、环境底声和拟音分轨。对白先校清晰度与相邻句响度，再铺同场底声，最后贴点声。制作输入需要音乐时另设音轨，在对白和关键信息出现的位置听校。优先用同一底声绕过对白和反应镜切点。需要用画外音或跨镜延续对白时，把声画错开作为明确剪辑选择登记。初次试听可用耳机和小音量扬声器各听一遍，遇到削波、可重复听见的噪声或关键字被掩盖就返工。最终响度和峰值按交付平台要求实测并登记。
4. 检查原生或后配对白。嘴部可见段以清楚的启闭、爆破音与主音为定位点，明显偏差时逐帧比对。主动设定的同步点以成片上约一帧为排查起点，连续两个或以上成片帧的固定偏移、句尾断口、人物说话错位或接触声落错时优先回调音轨或换镜。实际素材需要跨镜听见对白时按已确认剪点判断。

以下是供剪辑或审片协作复制的任务卡。剪辑工具可直接执行的裁切点由原片及时间线状态填写。

```text
确认基线 <<静帧粗剪版次和意图>>
选择镜头和音频 <<候选视频与对应干声版次>>
剪入和剪出 <<源片时间码与成片时间码>>
要听清的台词与动作点 <<已确认的内容与标记>>
色调和底声基准 <<锁定画面和音轨>>
保留用于诊断的上下文 <<相邻镜头与过渡>>
```

## 3. SRT 与连放复核

1. 音画剪定后，按最终时间线重新从实听对白放置字幕。先核对已确认的原句，再标字幕入出。保存独立 UTF-8 SRT，递增编号，时间码采用 `HH:MM:SS,mmm`，避免重叠、倒序或越过成片结尾。字幕用于预览时在播放器或剪辑软件挂载。
2. 按实际导出的成片帧率检查句首、句末、反应镜与切场位置。逐帧查看实际音画，并用播放器重新挂载 SRT 复核几处明显的起落和边界。格式合规只能说明可解析，实际同步以导出后的播放检查为准。
3. 对照上一可用版本连续播放选中的整段。先看一次确认信息和表演连贯，再按 [06 样片验收表](06_样片验收_模板.md) 回看具体时间码，检查执行输入、身份和空间、主动作和终态、口型和字幕。初轮相邻镜头通过后才扩大生成。后续每批看和已通过镜头之间的接点。
4. 发现失败时冻结问题镜，不把它作为后续引用或已验收片段。记录旧版和新版、问题时间码、归因及下一轮唯一改动。修复后换入同一段上下文重看。两次重试都未改善同一缺陷或预算用尽时，在时间线留待处理标记，回到粗剪、资产、动作拆分或干声工序解决。

## 4. 交 G5 的版本记录

记录选定的样片和整集版本、分辨率与帧率、精确文件名、成片实际时长、所用音轨与独立字幕、最终采用的镜头版本、质检记录和仍待核准的事项。成片与 SRT 使用同一版本号。新剪辑、新混音或字幕改动输出一组新版本，同时保留旧版与本次差异。文件命名、交接清单和存放路径见 [成片目录](../../out/README.md)。
