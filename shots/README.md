# shots 导演分镜目录指南（通用模板）

本目录由**【窗口③ 导演分镜拆解专员】**专属负责写入，资产与视频窗口只读。

## 每集标准交付三件套

每集解析剧本后，必须交付以下 3 个标准化文件：

1. **`shots/EXX_master.md`（13 列分镜总控表 · 非提交）**：
   - 登记全场情绪、时长（Cadence Wave 起伏）、角色在场状态码（🎬 出镜 / 👂 画外 / ❌ 不在场）、挂载模式（A/B）、依赖资产清单与声学过渡桥标记。
2. **`shots/EXX.md`（Seedance 2.5 网页即粘即用版生视频提示词集）**：
   - 每镜由「2 行元数据卡头」+「1 个纯净 ```text ... ``` 代码块」组成；
   - 严格落实 **8 大补偿层**：机位、站位、非线性动效（蓄力➔爆发➔收力终态）、三层动态环境预算、生理机理翻译、音轨白名单；
   - 视频窗口全选代码块即可直粘进 Seedance 2.5 出片。每镜末尾保留「不要生成旁白字幕、台词字幕或对白字幕。」生成画面不烧台词字。
3. **`shots/EXX_assets_todo.md`（《本集资产需求派单表》）**：
   - 清单化列出本集所需的全部图片类资产（纯人物三视图 `CHR-*-TURN`、变体 `CHR-*-EXP/STATE`、场景四宫格 `SCN-*-GRID`、白模站位图 `BLK-*-*`、道具 `PRP-*`、首帧 `FRM-*`）；
   - 附带生图提示词，指引【窗口② 资产窗口】在通用画布通过 `0 积分畅用` 查漏补缺。

## 提交前必须通过的自动化预检门禁

在把分镜交付下游或通知资产窗口前，必须运行：
```bash
python 02_规范与工具/tools/audit_shots.py shots/EXX.md --skip-lock
```
资产还没画完时加 `--skip-lock`。正式出片前去掉它，连同锁版和挂载图是否落盘一起查。动作预算（一拍一个主动作）在试拍卡点人工看，不靠这条脚本。
